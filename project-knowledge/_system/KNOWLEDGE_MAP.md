# Mapa Inicial de Conhecimento

Este arquivo define os primeiros domínios que provavelmente merecem MOCs.

Não é uma taxonomia rígida. Novos MOCs devem nascer conforme o conhecimento crescer.

## MOCs iniciais

```text
MOC - GoDocs Docs
MOC - Arquitetura
MOC - Produto
MOC - Documentação
MOC - Design System
MOC - UX e Navegação
MOC - Busca
MOC - Segurança
MOC - Redesign
MOC - Editor
MOC - Ferramentas e Desenvolvimento
```

## MOC principal

`MOC - GoDocs Docs` será o ponto de entrada.

Ele deve apontar para os MOCs especializados, evitando transformar-se em um arquivo gigante.
