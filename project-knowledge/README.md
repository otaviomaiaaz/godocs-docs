# GoDocs Knowledge — Obsidian + Zettelkasten

Este diretório é o **cérebro de conhecimento do desenvolvimento do GoDocs Docs**.

Ele existe para registrar, conectar e recuperar conhecimento de engenharia, produto, UX/UI, documentação, arquitetura, segurança, decisões em formação, pesquisas, aprendizados e problemas do projeto.

## Regra principal

`project-knowledge/` **não substitui as fontes canônicas** do projeto.

Quando houver conflito, a fonte canônica correspondente prevalece.

Exemplos:

- `AGENTS.md` → regras para agentes e Codex;
- `PRODUCT.md` → produto e princípios editoriais;
- `DESIGN.md` → Design System;
- `content/docs/` → documentação publicada;
- `project-docs/` → documentos formais, memória consolidada e estado operacional;
- repositório/código → estado executável real.

O Obsidian funciona como uma camada de conhecimento conectado que ajuda pessoas e agentes a entenderem **por que** decisões existem, como conceitos se relacionam e onde encontrar contexto.
