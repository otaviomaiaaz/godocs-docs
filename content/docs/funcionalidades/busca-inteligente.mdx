## Visão geral

A Busca inteligente permite encontrar documentos do workspace rapidamente, usando IA semântica para interpretar o que está sendo procurado.

## Como funciona

A busca é feita a partir de um campo de pesquisa central. Para refinar os resultados, o botão **Avançado** abre um painel com opções de filtro.

## Como utilizar

1. Digite o termo desejado no campo de busca.
2. Se necessário, clique em **Avançado** para abrir o painel de filtros.
3. Selecione os critérios desejados.
4. Clique em **Aplicar filtros** para atualizar os resultados com base na seleção.

O painel de filtros conta com os seguintes critérios:

- **Ordenar por** — define a ordem de exibição dos resultados. A opção padrão é **Relevância**.
- **Pastas** — restringe a busca a uma pasta específica do workspace. A opção **“Todas as pastas”** mantém a busca em todo o ambiente, e pastas com uma seta ao lado indicam que possuem subpastas.
- **Tipos de documentos** — filtra os resultados considerando apenas um tipo específico de documento.
- **Data** — filtra por período, com base na data de criação, usando os campos **De** e **Para**.
- **Autor/Proprietário** — filtra os resultados pela pessoa responsável pelo documento.
- **Aplicar filtros / Limpar filtros** — botões na parte inferior do painel. O primeiro confirma os critérios selecionados; o segundo remove todos os filtros aplicados.
